# 5G 자동 제어 — 사용 설명서

5G가 자꾸 붙었다 끊기는 곳에서 폰을 **잠깐 LTE로 쉬게** 했다가, 좀 있다 **다시 5G를 확인**하는 앱이에요. 배터리·발열이 신경 쓰이는 5G 불안정 구간에서, 사용자가 고른 "5G 우선"은 그대로 둔 채 실제 연결만 잠깐 쉬어 줘요.

> 자세한 그림 설명은 앱을 열고 **[도움말]** 칸에서 볼 수 있어요(이 설명서와 같은 내용).

## 이 폰에서 되나요?

- 대상은 **삼성 갤럭시**예요. 그중에서도 보안 업데이트가 **2025년 12월 이전**에 머문 기기(예: 노트20 울트라급·그 이전)에서 잘 돼요. 그 뒤 업데이트를 받은 최신 기기는 구글·삼성이 막아 **대부분 안 돼요**.
- **외우실 필요 없어요.** 앱이 직접 해 보고 알려 줘요. 앱 → **[설정] → "이 폰에서 되는지 점검·결과 보내기"**를 누르면 "됩니다 / 안 됩니다 / 아직 모름"으로 판별해요. 안 되는 폰은 아무것도 바꾸지 않고 "지원 안 함"으로 안내해요.

## 설치와 처음 설정 (처음 한 번, PC 필요 없음)

1. 설치 파일(APK)을 폰에 설치해요.
2. 앱을 처음 열면 **[시작하기]** 체크리스트가 떠요. 끝난 단계는 앱이 폰을 읽어 자동으로 ✓가 돼요. 지금 할 단계만 펼쳐서 버튼으로 안내해요.
   1. **Wi-Fi 연결** (인터넷이 안 되는 Wi-Fi여도 됨. 핫스팟만 켠 상태나 모바일 데이터로는 다음 단계가 안 켜져요)
   2. **개발자 옵션 켜기** (설정 → 휴대전화 정보 → 소프트웨어 정보 → '빌드번호' 7번 누르기)
   3. **무선 디버깅 켜기** (개발자 옵션. 처음 붙은 Wi-Fi면 '허용')
   4. **6자리 코드 넣기** ('페어링 코드로 기기 페어링'을 눌러 코드 창을 띄운 채, 위 알림창을 내려 앱 알림에 넣거나 화면을 나눠 앱 칸에 넣기). 앱이 폰이 인정하는 목록 끝에 자기 줄 하나를 덧붙이고(기존 줄은 그대로), 권한을 확인한 뒤 무선 디버깅을 꺼요.
   5. **빠른 설정에 '5G 자동' 타일 추가**
   6. **배터리 최적화에서 빼기** (오래 살아 있게)
   7. **자동 제어 켜기**
- 왜 이런 설정이 필요한지는 [도움말] 맨 위 "처음 설정은 왜 필요한가"에 그림으로 있어요.

## 평소 사용

- 삼성 설정(연결 → 모바일 네트워크 → 네트워크 모드)에서 **5G 우선**을 고르고, **자동 제어가 켜져 있으면** 앱이 알아서 지켜봐요. 5G가 자꾸 끊기면 잠깐 LTE로 쉬었다가 다시 확인해요.
- **LTE 우선**을 고르면 앱은 쉬어요(아무것도 바꾸지 않고, 앱이 걸어 둔 막음이 있으면 풀어요).
- 빠른 설정의 **'5G 자동' 타일**로 자동 제어를 켜고 꺼요. 재부팅해도 스스로 다시 켜져요.
- **평소엔 Wi-Fi·무선 디버깅·PC가 필요 없어요.** 무선 디버깅은 처음 설정 때만 잠깐 써요.
- SIM 교체·기기 업데이트 등으로 등록이 풀리면 앱이 "처음 설정 필요"를 띄워요. [시작하기]로 다시 하면 돼요.

## 안전·개인정보

- 사용자가 설정에서 고른 5G 우선/LTE 우선(설정 화면 값)은 **절대 바꾸지 않아요.** 쉬는 동안에만 실제 5G 연결을 잠깐 막아요.
- 폰이 인정하는 목록에는 이 앱 줄 **하나만** 더해요(기존 줄은 그대로).
- "결과 보내기"에 담기는 건 기기·안드로이드 버전·보안 패치월·통신사 표시 이름·점검 결과뿐이고, **전화번호·기기 일련번호 같은 개인정보는 담지 않아요.**

## 화면

- **[지금]** 지금 상태·이유·다음 할 일·오늘의 활동
- **[활동 기록]** 최근 24시간 ([폰 상태]/[앱 판단]/[앱이 바꿈])
- **[상세]** 문제 생겼을 때 자세한 값
- **[설정]** 자동 제어 켜기·끄기, 시작하기 다시 보기, 타일 추가, 배터리 최적화 제외, 이 폰 점검
- **[도움말]** 경우별 그림 설명
- **[시작하기]** 처음 설정·마무리 체크리스트
